# Top Tower 상업화 개발계획

> 목적: 방치형 타워 게임 Top Tower를 **상업 출시(F2P 수익)** 가능한 제품으로 만들기 위한 현실적 개발 로드맵.
> 대상 독자: 개발 당사자(소규모/1인 기준). 수치·KPI는 업계 벤치마크 기반의 목표치이며 소프트런치 데이터로 재튜닝한다.

---

## 0. 요약 (TL;DR)

- **정체성**: "세계 도시의 문화를 층층이 수집하는 캐주얼 방치 타워." 차별화 훅 = **도시 문화 컬렉션**(도쿄 → 오사카/서울/…).
- **수익 모델**: 광고 중심 하이브리드(리워드 광고 + 프리미엄 재화 IAP + 도시 테마팩 + 시즌패스). 코어 재미를 막는 P2W/에너지 금지.
- **핵심 원칙**: 도시 하나(도쿄)로 **끝까지 리텐션 되는 수직 슬라이스**를 먼저 완성 → 소프트런치로 검증 → 그 다음 도시 확장. 절대 도시 10개부터 벌리지 않는다.
- **당장의 최우선**: 저장 시스템 + 세입자 기반 수입 + 오프라인 수익. 이게 없으면 상업 방치겜이 성립하지 않음(현재 전무).

## 1. 제품 정의

| 항목 | 내용 |
|---|---|
| 장르 | 방치형(Idle) + 수집 + 라이트 경영 |
| 레퍼런스 | Tiny Tower(수집·복원 루프), AdVenture Capitalist(지수 성장·프레스티지), Project Highrise(경영·비주얼) |
| 플랫폼 | 모바일 세로 9:16 (Android 우선 → iOS) |
| 타깃 | 캐주얼~미드코어, 방치/수집/도시빌더 선호층. 30~40대 포함 폭넓음 |
| 차별화 훅 | **실제 도시의 고유 업종/문화를 수집** (도쿄: 초밥·라멘·캡슐호텔·파칭코·게임센터·오마카세…) |
| 세션 설계 | 짧고 잦은 접속(하루 3~6회, 회당 1~3분). 방치로 쌓이고, 접속해서 수거·건설·업그레이드 |

**북극성 문장**
> 세계 도시를 테마로, 각 도시의 고유 세입자를 수집하며 타워를 올리는 캐주얼 방치 수집겜.
> 재개발(프레스티지)로 반복 성장하고, 신규 도시·한정 세입자 이벤트로 계속 돌아오게 만든다.

## 2. 비즈니스 모델

### 2.1 수익 구조 (우선순위 순)

| 우선 | 수단 | 형태 | 비고 |
|---|---|---|---|
| 1 | **리워드 광고** | 오프라인 수익 2배 / 현재 수입 일정시간 2배 / 건설 즉시완료 / 무료 젬 / 오프라인 시간 연장 | 캐주얼 방치겜 수익의 핵심. 유저가 **원해서** 보는 광고 |
| 2 | **프리미엄 재화(젬)** | 시간 스킵, 가챠, 편의 | IAP로 판매 + 광고/미션으로 소량 지급 |
| 3 | **Remove Ads / 스타터팩** | 1회성 IAP | 전환율 높은 저가 상품. 광고 제거는 스트레스 해소형 |
| 4 | **도시 테마팩** | 신규 도시 조기해금 / 프리미엄 스킨 | 콘텐츠 구조와 완벽히 합치 |
| 5 | **시즌 패스** | 이벤트 연동 배틀패스 | 라이브옵스 정착 후 |
| 6 | **가챠(특별 세입자)** | 도감 연결 한정 세입자 | 수입 배수는 완만하게(P2W 방지), 주로 수집·연출 가치 |

### 2.2 금지 사항 (리텐션 파괴 요소)
- 코어 루프(층 쌓기·수거)를 막는 **에너지/스태미나** 시스템.
- 강제 전면광고(interstitial) 남발 — 넣더라도 최소화하거나 옵트인.
- 노골적 P2W(과금해야만 진행되는 벽).

### 2.3 현실적 KPI 목표 (소프트런치 판단 기준)

| 지표 | 최소 생존선 | 양호 |
|---|---|---|
| D1 리텐션 | 35% | 45%+ |
| D7 리텐션 | 12% | 18%+ |
| D30 리텐션 | 4% | 7%+ |
| ARPDAU | $0.02 | $0.05+ |
| 세션/일 | 3 | 5+ |

> 이 수치가 소프트런치에서 안 나오면 **글로벌 출시 전에 코어·경제를 고친다.** 마케팅비를 태우기 전 반드시 검증.

## 3. 코어 루프 & 리텐션 설계

### 3.1 두 축의 역할 분리 (이미 있는 시스템 활용)
- **세입자(자동 임대)** = 방치 수익. 오프라인에도 쌓임. "숫자가 올라간다"의 근원.
- **방문객(수동 수거)** = 접속 이유. 탭·수거·특별 방문객(수집/뽑기 훅).

### 3.2 리텐션 4기둥
1. **오프라인 수익 상한** — "N시간이면 꽉 참" → 그 전에 복귀.
2. **손 닿을락 말락 한 다음 목표** — 다음 층/세입자/도시가 늘 조금 모자란 골드(지수 곡선).
3. **재개발(프레스티지)** — 밀고 다시 지으면 영구 배수. 방치겜 수명의 핵심.
4. **정기 이벤트** — 한정 세입자·도시 축제. 도시 테마 구조라 무한 생성.

## 4. 현재 상태 진단 (2026-08 기준)

### 있는 것 (자산)
- 그리드/큐브 빌딩 시스템, 스테이지 프리팹 동적 로드(Addressables).
- 세입자 유치 → 실내공사 → 입주 플로우, 방 정보 팝업, 카메라 스크롤/줌.
- 골드 화폐(기본), 모듈 타입 시스템 + 데이터, **이미지 자동 최적화 파이프라인**.
- 도쿄 테마 모듈 40여 종 + 한글 작명.

### 없는 것 (상업화 필수 공백)
| 공백 | 영향 |
|---|---|
| **저장/로드 시스템 전무** | 앱 끄면 골드·건물 전부 리셋. 진행이 세션도 못 넘김 |
| **세입자 수입 미연결** | `dailyRent`가 표시만. 건물 지어도 수입 안 늚(초당 10 고정) |
| **오프라인 수익 없음** | 방치겜의 심장 부재 |
| 프레스티지/업그레이드 | 장기 리텐션 메타 없음 |
| 컬렉션/도감 UI | 수집 훅 미구현 |
| 수익화(광고/IAP/젬) | 매출 파이프 전무 |
| 온보딩(FTUE) | 초반 이탈 방어 없음 |
| Analytics | 데이터 기반 튜닝 불가 |

## 5. 개발 로드맵

> 각 Phase는 이전 Phase에 의존. **Phase 0~3을 도쿄 한 도시에 완성 = 소프트런치용 수직 슬라이스.**
> 규모 표기는 1인 기준 상대 크기(추정). 실제 일정은 가용 시간에 맞춰 조정.

### Phase 0 — 방치 기반 인프라 (최우선) [크게]
- **저장/로드 시스템**: 골드, 층별 슬롯 상태, 마지막 저장 시각(UTC), (추후) 프레스티지·업그레이드. JSON 파일 방식.
- **세입자 기반 수입**: 총 수입률 = Σ(입주 세입자 rate) × 배수. GoldManager를 고정값 → 수입률 기반으로 전환.
- **오프라인 수익 + 정산 팝업**: 복귀 시 경과시간 × 수입률(상한 적용) 지급 + "그동안 N 벌었어요"(광고 2배 버튼 자리).
- **성장 곡선 v1**: 비용/수입/업그레이드 지수 곡선 엑셀 설계.
- 완료 기준: 껐다 켜도 진행이 유지되고, 방치로 쌓이며, 세입자를 지을수록 수입이 는다.

### Phase 1 — 코어 진행 & 리텐션 메타 [크게]
- **세입자 업그레이드(Lv업)**: 골드 소비처 + 목표. rate 배수.
- **재개발(프레스티지)**: 리셋 + 누적 실적 기반 영구 배수 화폐(명성/랜드마크).
- **세입자 도감/컬렉션 UI**: "도쿄 N종 中 M 수집."
- **방문객 능동 루프 강화**: 수거 연출, 특별 방문객(희귀 드롭·수집).
- 완료 기준: 장기 목표(도감 완성·프레스티지 배수)와 반복 이유가 생김.

### Phase 2 — 온보딩 & 게임필 [중간]
- **FTUE**: 첫 세션 튜토리얼 + 초반 훅(빠른 첫 건설·첫 수입 쾌감).
- **연출/사운드**: 수입 팝업, 건설 이펙트, BGM(도시 테마), 햅틱.
- **편의 기능**: 자동수거, 빠른 건설/업그레이드 UI, 수입률 표시.
- 완료 기준: 초반 이탈(D1) 방어. 첫 10분이 재미있음.

### Phase 3 — 수익화 레이어 [중간]
- **프리미엄 재화(젬) + 상점**.
- **리워드 광고 연동**(오프라인 2배 / 수입 부스트 / 즉시완료 / 무료젬 / 오프라인 연장).
- **Remove Ads IAP, 스타터팩**.
- **가챠(특별 세입자)** — 도감 연결.
- 완료 기준: 매출 파이프 작동. (여기까지가 소프트런치 최소 구성)

### Phase 4 — 라이브옵스 & 콘텐츠 확장 [지속]
- **이벤트 프레임워크**: 한정 세입자·도시 축제(도쿄 벚꽃/마츠리).
- **일일 미션/로그인, 시즌 패스**.
- **2번째 도시**(오사카 또는 서울) — 콘텐츠·수익 확장 구조 검증.
- 완료 기준: 지속 리텐션·매출. 콘텐츠 파이프라인 검증.

### Phase 5 — 소프트런치 → 글로벌 [출시]
- **Analytics 계측**(리텐션·퍼널·매출 이벤트).
- **소프트런치**(캐나다/필리핀 등 소규모) → KPI 확인 → 튜닝.
- **ASO/스토어 페이지/마케팅 소재**.
- KPI 생존선 통과 시 **글로벌 출시** + UA(유저획득) 시작.

## 6. 경제/수익화 시스템 상세 (설계 지침)

### 6.1 화폐 체계
- **골드**(소프트): 건설·업그레이드. 방치·수거로 획득. 지수적으로 소모.
- **젬**(하드): 시간 스킵·가챠·편의. IAP 주력 + 소량 무료 지급.
- **명성/랜드마크**(프레스티지): 재개발로 획득, 영구 배수. 판매 대상 아님(순수 진행 메타).

### 6.2 성장 곡선 원칙
- 비용: `cost(k) = base × r^k` (r ≈ 1.15). 다음 목표가 늘 조금 버겁게.
- 세입자 수입은 비용보다 **약간 완만**하게 증가 → "하나 더" 트레드밀.
- 프레스티지 배수로 반복마다 벽을 넘게 함.
- **수치는 엑셀로 먼저 → 합의 후 코드에 데이터로 주입**(하드코딩 금지, 튜닝 가능하게).

### 6.3 광고 설계
- 리워드 위주(유저 자발). 오프라인 정산 팝업의 "2배" 버튼이 최대 노출 지점.
- 전면광고는 최소/옵트인. 광고 SDK는 미디에이션(AdMob/Max) 검토.

## 7. 라이브옵스

- **콘텐츠 캐던스 = 신규 도시/한정 세입자.** 도시 하나가 곧 이벤트·테마팩·가챠 풀.
- 이벤트: 시즌(축제) 한정 세입자 → 도감 수집 욕구 + 매출.
- 리텐션 장치: 일일 로그인, 일일/주간 미션, 시즌 패스.
- 운영 데이터로 곡선·상점·광고 위치 지속 튜닝.

---

## 8. 출시 전략

1. **수직 슬라이스 완성**(Phase 0~3, 도쿄 1도시) → 내부 검증.
2. **소프트런치**(소규모 국가) → Analytics로 D1/D7/ARPDAU 측정.
3. 생존선 미달 시 **코어/경제 개선 후 재측정**(마케팅비 태우기 전).
4. 통과 시 콘텐츠(2번째 도시)·라이브옵스 보강 → **글로벌 출시** + UA.

---

## 9. 리스크 & 스코프 원칙

- **시장 포화**: 방치겜은 레드오션. 이기는 건 (a) 차별화 훅(도시 문화 수집), (b) 튜닝된 경제, (c) 라이브옵스. 셋 다 필요.
- **스코프 폭주 금지**: 도시 10개, 복잡 경영 시스템부터 벌이지 않는다. **도쿄 1도시 완성 후 확장.**
- **경제 튜닝이 성패**: 곡선을 대충 잡으면 리텐션이 죽는다. 엑셀 → 소프트런치 데이터로 반복 보정.
- **1인 개발 리소스**: 아트·사운드·광고SDK·스토어운영까지 필요. 외주/에셋/툴 활용 적극 고려.
