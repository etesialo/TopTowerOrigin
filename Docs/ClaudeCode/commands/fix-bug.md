# Bug Fix Workflow

## Step 1: Analyze

에러 메시지 또는 버그 설명을 받으면:
1. 에러 로그에서 파일명, 줄번호, 스택트레이스 확인
2. 해당 코드 읽기
3. 원인 파악

**과도한 추측 금지. 에러 메시지를 믿고 해당 코드만 확인.**

## Step 2: Fix

- 최소한의 변경으로 수정
- 관련 없는 코드 리팩터링 금지
- Debug.Log 마커로 수정 코드가 컴파일되었는지 확인

## Step 3: Verify

- 원래 에러가 해결되었는지 확인
- 다른 기능에 부작용이 없는지 확인

## Critical Rules
1. 수정 범위를 최소화 — 버그와 직접 관련된 코드만 수정
2. 2번 시도해도 해결 안 되면 → /clear 후 다른 접근
3. "fix" 한 마디에 가장 좋은 결과가 나옴 — 과도한 설명보다 에러 메시지 그대로 전달
