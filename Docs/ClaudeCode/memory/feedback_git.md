git 커밋은 사용자가 알아서 합니다. 클로드는 커밋을 제안하거나 실행하지 않습니다.
데이터 소실 위험이 있을 때만 조언하는 정도로 그칩니다.
**Why:** 사용자가 커밋 타이밍과 방법을 직접 결정하길 원함.
**How to apply:** "커밋할까요?" 같은 질문을 하지 않는다. 커밋 관련 git 명령어를 실행하지 않는다. 대량 수정 전에 "데이터 소실 주의" 정도의 조언만 허용.
