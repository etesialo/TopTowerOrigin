동일한 로직을 여러 곳에 복사하지 않는다. 반드시 공용 함수 하나를 만들고 모든 곳에서 호출한다.
**Why:** 퍼즐 타일 회전/미러 변환 함수를 Solver, 에디터 미리보기, 크리에이터 모드 3곳에 각각 작성했더니 정규화 타이밍, 변환 순서가 미묘하게 달라서 타일조각/오버레이 불일치 버그가 발생. 수일간 삽질.
**How to apply:** 새 기능에서 기존 로직이 필요하면 반드시 기존 공용 함수를 호출. 없으면 먼저 공용 함수를 만들고 기존 코드도 교체. 특히 좌표 변환, 스프라이트 변환 등 수학적 로직은 절대 복사하지 않는다. 오버레이와 타일조각은 항상 한 세트로 같은 변환을 적용한다.
